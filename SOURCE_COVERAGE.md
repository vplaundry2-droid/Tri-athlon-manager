# Source coverage

116 local PDFs indexed: 100 Masters cycling documents and 16 SSISA documents. Raw PDFs and extracted text remain local and are not included in this repository or the hosted bundle. This is an inventory and implementation audit, not a claim that all documents or every page were fully reviewed. Titles below are source identifiers, not reproduced course content.

Review levels: **full text** = extracted text reviewed throughout (not every image); **selected** = summaries or selected passages reviewed, not a full audit. Key strength/concurrent-training tables were also rendered for inspection. All sources still need a systematic claim-by-claim validation before a scientifically calibrated simulator could be claimed.

“Partial” means only the stated abstraction exists. “Deferred” is not implemented. Implementation details and conflicts are in [MODEL_PRINCIPLES.md](MODEL_PRINCIPLES.md). No document supplies the numerical potential, injury or muscle-growth rules used in this game.
